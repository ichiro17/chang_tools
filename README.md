# 🧰 小張的小工具箱

給老師的課堂小工具集 —— 打開就能用，免登入、免安裝。
點名抽籤、課堂時鐘、投影指令、放假倒數，一個網站搞定。

線上網址：https://github.com/ichiro17/chang_tools

---

## 工具

### 🎡 抽籤轉盤 · `/draw`

貼上一份名單，轉盤就會隨機抽人。上課點名、分組、抽獎都好用。

- 三步驟：貼上名單 → 設定抽法 → 開始抽籤，即時顯示已載入人數
- 自動略過空白列與前後空白，重複姓名會提醒，可合併或保留
- 一次抽 1 位或多位，每人機率相同；抽中自動移除，避免同一輪重複
- 抽中後大字顯示結果，可「再抽一位」或「放回名單」
- 投影畫面只顯示轉盤與結果，空白鍵抽籤
- 「清空名單」5 秒內可復原

### 🕐 課堂時鐘 / 考程 · `/timer`

投影幕上顯示現在時間，並依你排好的課堂流程或考程，自動秀出「現在進行的項目」與剩餘時間。

- 「課堂流程」與「考試考程」兩種模式，內建國小、國中課表與段考範例
- 即時檢查時間：名稱空白、時間不完整、結束早於開始、項目重疊都會直接標出來
- 24 小時制輸入，已結束的項目自動收合
- 投影畫面獨立在 `/timer/display`：控制台改課表，投影分頁自動同步（快捷鍵 `F` 全螢幕）
- 「我的課表」：存好幾組課表（例如「五年級自然課」「段考第一天」），一鍵載入
- 課表可匯出成 JSON 檔，換電腦、換教室時再匯入
- 資料存在瀏覽器本機（localStorage）

### 🏫 課堂模式 · `/classroom`

按一個按鈕，投影幕就切成清楚的課堂指令：安靜作業、小組討論、看老師⋯⋯

- 五種課堂模式一鍵切換（數字鍵 `1`–`5`），目前模式有明顯外框與「目前使用中」標籤
- 內建倒數與時間到響鈴，空白鍵開始／暫停
- 聲音設定預設只顯示開關與音量，白噪音、背景音樂等收在「更多聲音設定」
- 「開始全螢幕投影」或「開啟投影預覽」，投影畫面有可隱藏的快捷鍵提示

### 🏖️ 撐到放假 · `/countdown`

寒假 / 暑假倒數，再算算扣掉週末與假日後，真正還要上幾天班、幾小時。

- 「撐到寒假」「撐到暑假」一鍵切換，倒數到秒
- 內建 115 學年度行事曆與人事行政總處國定假日（含補假），頁面標示資料版本與來源
- 「計算方式」說明扣掉了哪些日子，數字怎麼來的一清二楚
- 接下來的小目標：週末、下一個連假、自訂事件（段考、校慶、發薪日）、寒暑假分段倒數
- 今天：是否為工作日，加上每日一句教師生存語錄（可自己新增）
- 學期里程碑與成就徽章：撐過第一週、學期過半、倒數 100 天⋯⋯日期到了自動解鎖
- 我的學校行事曆：自訂不上班日與補課日
- 設定存在瀏覽器本機（localStorage）

## 技術

- [Next.js 16](https://nextjs.org)（App Router、Turbopack）
- React 19
- [Tailwind CSS v4](https://tailwindcss.com)
- TypeScript

沒有後端、沒有資料庫；所有設定都存在使用者自己的瀏覽器。

## 本機開發

```bash
npm install
npm run dev
```

開 [http://localhost:3000](http://localhost:3000)。

其他指令：

```bash
npm run build   # 產生正式版
npm run start   # 跑正式版
npm run lint    # ESLint
```

## 專案結構

```
app/
├── page.tsx            首頁（任務導向入口）
├── layout.tsx          根 layout
├── globals.css         全站顏色（每個工具一個主題色）、焦點外框
├── draw/               抽籤轉盤（page.tsx + Wheel.tsx 轉盤）
├── timer/              課堂時鐘 / 考程
│   ├── page.tsx        控制台（編課表）
│   ├── display/        投影畫面 /timer/display
│   ├── Board.tsx       投影畫面內容（控制台預覽也用它）
│   ├── SavedSchedules.tsx 我的課表、匯入／匯出
│   └── schedule.ts     課表資料、時間檢查、分頁同步
├── classroom/          課堂模式（page.tsx + audio.ts 音訊引擎）
├── countdown/          撐到放假
│   ├── page.tsx        倒數與工作量卡片
│   ├── sections.tsx    今天、小目標、里程碑、計算方式
│   ├── SettingsSheet.tsx 教師手帳設定
│   └── calendar.ts     行事曆、工作日、里程碑計算
└── components/
    ├── ToolHeader.tsx  四個工具共用的頁首、按鈕樣式
    ├── Icon.tsx        共用線條圖示
    └── FlipClock.tsx   共用翻頁時鐘元件
```
